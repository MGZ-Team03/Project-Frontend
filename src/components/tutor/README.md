# 📁 components/tutor

튜터 전용 컴포넌트

## 파일 목록

### 1. StudentCard.jsx
학생 상태 카드 컴포넌트

**Props:**
```javascript
{
  student: {
    email: string,
    name: string,
    status: 'active' | 'warning' | 'inactive',
    activity: 'sentence' | 'ai_chat' | null,
    speakingRatio: number,
    duration: number,
  },
  onClick: function,
}
```

**기능:**
- 학생 이름, 현재 활동, 발음 비율, 학습 시간 표시
- 상태에 따른 색상 표시 (🟢/🟡/🔴)
- 클릭 시 상세 모달 열기

**화면 예시:**
```
┌──────────────────────────────┐
│ 🟢 박영어  문장연습  85%  12분│
└──────────────────────────────┘
```

---

### 2. StudentDetailModal.jsx
학생 상세 정보 + 피드백 모달

**Props:**
```javascript
{
  student: object,      // 학생 정보
  isOpen: boolean,
  onClose: function,
}
```

**기능:**
- 학생 현재 상태 상세 표시
- 현재 학습 중인 문장 표시
- 피드백 입력 및 전송
- 최근 학습 이력 표시

**화면 예시:**
```
┌──────────────────────────────────────┐
│  👤 최토익                      [X]  │
├──────────────────────────────────────┤
│  현재: 문장 연습 (발음 30%)          │
│  문장: "The weather is nice today"   │
│  오늘: 8분 학습                      │
├──────────────────────────────────────┤
│  💬 피드백                           │
│  ┌──────────────────────────────┐   │
│  │ 따라 읽어보세요!              │   │
│  └──────────────────────────────┘   │
│         [전송]                       │
├──────────────────────────────────────┤
│  📈 최근 학습 이력                   │
│  1/6: 35분 (75%) | 1/7: 28분 (68%)   │
└──────────────────────────────────────┘
```

**API 호출:**
- `POST /api/tutor/feedback` - 피드백 전송
