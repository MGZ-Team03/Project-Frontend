# 📁 pages/tutor

튜터용 페이지 컴포넌트

## 파일 목록

### 1. DashboardPage.jsx
튜터 대시보드 페이지

**기능:**
- 담당 학생 목록 실시간 표시
- 학생 상태 표시 (🟢 발음 중 / 🟡 주의 / 🔴 미활동)
- 학생 클릭 시 상세 모달 표시
- WebSocket으로 학생 상태 실시간 수신

**사용 컴포넌트:**
- `Header`
- `StudentCard`
- `StudentDetailModal`

**API 호출:**
- `GET /api/tutor/students` - 담당 학생 목록
- `GET /api/tutor/students/{email}` - 학생 상세
- `GET /api/tutor/students/{email}/history` - 학습 이력
- `POST /api/tutor/feedback` - 피드백 전송

**WebSocket 이벤트:**
- `STUDENT_UPDATE`: 학생 상태 업데이트 수신
- `STUDENT_CONNECT`: 학생 접속
- `STUDENT_DISCONNECT`: 학생 접속 종료
